# Storyboard

The film tells developers: different tasks can receive different model and
effort choices while the conversation stays together.

## Frame 1 — The juggler (0–9s)
status: animated
src: source/film.js — opening
motion: spring-pop-entrance; svg-path-draw; original jointed character gestures

A paper creature is juggling a file, a folded blueprint and a tangled bug.
Each object has distinct timing and weight. The red conversation thread catches
them. Headline: “TASKS CHANGE.” A small question follows: “SWITCH BY HAND?”

## Frame 2 — The route-keeper (9–14.7s)
status: animated

The creature gestures beside the thread as it curls around the task objects.
The product name writes on, followed by “ONE CONVERSATION” and “AUTO MODE.”
