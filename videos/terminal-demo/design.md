# Terminal replay

A single portrait terminal follows three consecutive turns in one recorded
conversation. The persistent window makes model retention visible. The only
model change in the edit follows the explicit `[route:coding]` directive.

- Canvas: 1080 × 1920, 30 fps, 35 seconds.
- Palette: warm paper `#F3F0E8`, forest ink `#19382F`, terminal `#121E1A`,
  muted green `#9BDCB7`, amber `#F0CF83` for the explicit choice.
- Typography: installed Arial for editorial labels and headings; installed
  Menlo for terminal content. The portable player has system-font fallbacks.
  Fonts are not redistributed. No externally loaded fonts or visual assets.
- Safe content area: x=72–1008, y=140–1735. Main terminal font is 37–40 px;
  captions are 46 px. Fine-print evidence labels are secondary information.
- Motion: time-indexed text reveals, a deterministic caret, a short vertical
  transition between turns, model-badge emphasis, and a progress rail. No
  simulated speed measurements or fabricated output.
- Audio: intentionally silent; captions carry the explanation.
- Evidence disclosure: persistent VERIFIED SESSION REPLAY, task mode,
  recording date, edited timing, and prompt-excerpt labels.

The model and effort readout is an editorial overlay derived from the router
records and native turn contexts; it is not a reproduction of a Codex UI widget.

Motion rules: `discrete-text-sequence` and `context-sensitive-cursor` from the
installed HyperFrames animation skill. All state derives from `frame(t)`;
seeking backward produces the same artwork as a fresh seek.
